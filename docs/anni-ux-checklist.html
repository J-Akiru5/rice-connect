Part C

Doing an action

Two actions to test on the live test version. ANNI should never do anything by herself — she proposes, you confirm. Follow the flow marks.

C1 · Place a buyer order live · buyer account

You ask→ Summary box→ You confirm→ Order placed + Undo

Ask: “Place an order for 40 sacks of restaurant rice for W3.” A summary should show sacks, type, week and the total price before anything happens.

C2 · Mark paid live · coordinator account

You ask→ Warning box→ You type the lot code→ Marked paid

Ask: “Mark the settlement for lot L-03 as paid.” This one genuinely cannot be undone — that is intended. The box should make you work a little: type the lot code to unlock Confirm, and Escape must not close it.
